# 从 Sunshine 到平板 SSH：一次小项目复盘

我一开始只是想在 vivo Pad 上看到并操作电脑画面。电脑端使用 Sunshine，平板端使用 Moonlight，目标看起来很简单，实际先遇到了安装目录和主程序不一致的问题，后来又处理了双屏、Tailscale 和平板 SSH。

最后跑通的是一条可用链路：Sunshine 与 Moonlight 已配对，平板能操作电脑，两个屏幕可以一次切换查看一个；Termux/OpenSSH 也完成过连接和一次重启后的启动验证。通过 Tailscale 添加电脑地址后，跨局域网进入 Moonlight Desktop 也验证过。

本地网络里我把 Moonlight 分辨率调到 2K，主观感受是清晰、流畅，几乎感觉不到延迟。这里没有测量端到端延迟、帧率、温度或长期耗电，所以这些数字不能从这次体验中推导出来。

这次最值得留下的不是某个固定地址或配置，而是排查顺序：先确认主程序和服务，再确认局域网配对，再处理显示器切换，最后用 Tailscale 扩展网络范围。SSH 只作为维护入口，不能被误解成 Android 屏幕控制方案。
