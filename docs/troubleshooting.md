# 排障记录

## 只有文件夹，没有 Sunshine 主程序

检查 `sunshine.exe`、服务和本机管理页面。不要因为目录名是 Sunshine 就认定安装完成；必要时卸载残留组件后，从官方发布页重新安装。

## Moonlight 只有主屏

先确认 Sunshine 识别到两个显示器，再用原生切屏快捷键逐个切换。不要把屏幕拼接、虚拟显示器和一次切换一个屏幕混为一谈。

## 2K 画面要求降低码率

这是编码分辨率、码率、网络带宽和设备解码能力共同作用的结果。降低码率可以改善连接建立或稳定性，但会牺牲清晰度；应在自己的网络上逐步调整并记录结果。

## SSH 重启后连不上

先在平板解锁并打开 Termux 看 `sshd` 是否运行，再检查 Termux:Boot 和后台限制。息屏保持连接与重启后自动启动是两件事，不能只验证其中一个。
